# Demo script (about 3 minutes)

Setup before going on stage: the laptop is on `/admin` and projected, 2–3 member iPhones have TU Alert open from the Home Screen, each phone has chosen a username (or tapped Skip), and each phone has tapped "Turn on alerts". The admin list includes sample reports marked "(Demo)".

1. **The problem (20 s).** "When the alarm goes off, most of us think it's a drill. When something breaks, our email disappears into silence."
2. **Report (40 s).** A member takes a photo with the iPhone, picks *Air conditioning*, picks Engineering Bldg 2, Floor 3, then Submit. The report appears on the projected admin queue.
3. **Status (30 s).** The admin sets it to Acknowledged, then In progress. The audience sees the phone update live on the member's screen (hold it up or mirror it).
4. **Confirmed alert (50 s).** The admin creates a *Confirmed incident* for the Engineering Administration Building, confirms "Is this real?", and sends. Every phone turns red: "CONFIRMED INCIDENT — NOT A DRILL". The room sees the live 3D building on the projector. The admin sets the fire start and closes any blocked stairs, and a member shows the 3D route on their phone. One member taps Need help, and their pin appears on the projector. The others tap I'm safe, and the admin counter goes 1, 2, 3. Optional: before this step, tap Show join QR so the class can join with alerts only; their phones must stay on the page.
5. **Drill (20 s).** The admin sends a Scheduled drill notice. The phones show the calm blue "no hazard" screen. "Two tiers, so the real one is never ignored."
6. **Close (20 s).** "Free pilot for one faculty, then THB 15,000–30,000 a year. Students never pay."

Backup: if anything fails, play the video recorded on 11 Nov and keep talking.
