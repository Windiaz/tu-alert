# TU Alert app

Vite + React + TypeScript + Tailwind PWA. See `../CLAUDE.md` and `../docs/PLAN.md`.

```bash
npm install
npm run dev       # dev server, also reachable from phones on the same Wi-Fi
npm run build     # type-check and production build
npm run test:ds   # SF231 data structure tests
```

Copy `.env.example` to `.env.local` for secrets. Never commit `.env.local`.
