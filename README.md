# TU Alert

Campus safety app for Thammasat: verified two-tier alerts plus facility reports with a visible status.

- `CLAUDE.md`: project context for Claude Code (read automatically)
- `docs/PLAN.md`: day-by-day plan to presentation day, 12 Nov 2026
- `docs/DEMO_SCRIPT.md`: what we show on stage
- `docs/MEMBERS.md`: team
- `design/`: prototype screens to match
- `reference/`: business canvas, persona, operation and marketing plans, cost Excel
- `app/`: the code (Claude Code creates it)

Start: open a terminal here and run `claude`, then say:
"Read CLAUDE.md and docs/PLAN.md, then start the Thu 5 Nov step."
